# Planner test versions

Test versions of the planner, not the live app. Nothing here changes the live app or its data.

- `/` : Muffin guide bunny test version (branch `muffin-guide`)
- `/fixed-home/` : fixed home screen test version, where only the goals list scrolls (branch `fixed-home-scroll`)

Each copy keeps its own saved data and offline cache, separate from the live app and from each other.
- `/screenshots/` : screenshots used in the pull requests
