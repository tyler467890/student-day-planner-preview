# Calo test versions

Test versions of Calo (the student planner), not the live app. Nothing here changes the live app or its data. The live app is at https://tyler467890.github.io/student-day-planner/.

Both test versions below shipped to the live app in [#28](https://github.com/tyler467890/student-day-planner/pull/28) and are kept here for reference only:

- `/` : guide bunny test version (built while he was still called Muffin; he is now Calo)
- `/fixed-home/` : fixed home screen test version, where only the goals list scrolls
- `/screenshots/` : screenshots used in the pull requests

Each copy keeps its own saved data and offline cache, separate from the live app and from each other.
